# Convox 💬

Convox is a real-time, room-based chat application built using **React**, **Node.js**, **Express**, and **Socket.io**.

Users can instantly join a chat room using a **username** and **room ID** — no authentication required — enabling fast and frictionless communication.

---

## 🚀 Features

- 🔗 Join chat rooms using username & room ID
- 💬 Real-time messaging with Socket.io
- 👋 User join / leave notifications
- ⬇️ Auto-scroll to latest message
- 🎨 Clean and minimal UI
- 🌐 Works across multiple rooms

---

## 🛠️ Tech Stack

### Frontend
- React (Vite)
- Tailwind CSS
- Socket.io Client

### Backend
- Node.js
- Express
- Socket.io

---



## ⚙️ How It Works

1. User enters a **username** and **room ID**
2. Client connects to the Socket.io server
3. User joins the specified room
4. Messages are broadcast in real time to all users in the room
